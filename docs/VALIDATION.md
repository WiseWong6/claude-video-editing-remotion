# 本次验证记录

验证日期：2026-09-28。环境：macOS、Node.js 24.19.0、npm 11.17.0、Chrome。Remotion 与播放器均固定为 4.0.529；精确依赖保存在 `package-lock.json`。

## 程序与成片

- `npm ci`：从锁文件重新安装依赖成功。
- `npm run check`：TypeScript 检查通过；三个时间轴测试通过，覆盖全部 900 帧、分段衔接、逆序跳转一致性及参数范围。
- `npm run build`：生成可直接通过本地文件路径打开的预览页，未启动预览服务器。
- `npm run render`：实际完成完整视频渲染，使用本机 Chrome。
- `npm run verify`：1280×720、30 帧/秒、900 帧、30 秒、包含音轨；整段 FFmpeg 解码无错误。
- 已从参考视频提取关键帧，核对素材布局、操作顺序、取景、配色、转场和结尾。复刻成片抽样检查十个时刻，并单独检查结尾；这是人工视觉核对，不是像素一致性测试。
- 音轨检测到非静音内容。音乐直接取自原片，声音混入导出视频。

## 本地预览实际操作

使用 Playwright 驱动 Chrome，通过 `file://` 打开生成的页面，实际检查：

- 播放后帧数推进，暂停后帧数稳定。
- 键盘可逐帧调整进度，鼠标可往回和往前拖动。
- 暂停时拖动仍保持暂停，播放时拖动结束恢复播放。
- 重播回到开头并开始播放，包括从末帧重播。
- 切换到 1.5 倍速后，实际总播放用时显示为 20 秒。
- 开启声音后音轨正常播放，暂停后静音。
- 空格可切换播放／暂停。
- 390 像素窄屏下播放条与页面没有横向溢出。
- 模拟「减少动态效果」后，重新加载时停留在第 0 帧。

预览调试期间修复了播放状态切换和音轨元素复用问题；采用显式播放／暂停指令及单一音轨元素后，上述检查通过。浏览器没有运行错误；Remotion 自带的许可提示不影响播放。
