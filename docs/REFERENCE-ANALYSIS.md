# 参考视频拆解

用户提供的片段页面：https://motionface.cc/?recording=e3ee409a-50f7-4b4a-af27-288226e47a57

本次通过本地视频读取到的事实：视频流为 1280×720、30 帧/秒、900 帧，画面时长 30.000 秒；原容器时长 30.058 秒，附带 48 kHz 双声道 AAC 音轨。复刻以 900 帧视频流为基准，音轨裁至画面长度。

## 构图与画面

- 奶油色全屏纸面，上方为文件名、时间码与导出按钮；左侧是素材／转场／文字栏，中央是竖屏手机，右侧是四个参数滑条，下方为剪辑时间轴。
- 色彩以纸白 `#f6f3e9`、炭黑 `#302d27`、珊瑚红 `#c96f58`、薄荷绿 `#7ebdb3`、金黄 `#f2cf65` 为主；素材中加入夜空蓝紫、拉面暖黄、柴犬浅绿与舞池粉紫。
- 黑色描边略有错位，机器人为方形红色身体、四条短腿、简单眉眼。手臂随操作拉成长线，末端保持圆形。
- 中文为手写风，标题并非标准界面字体。复刻使用霞鹜文楷近似；原片字体身份未确认，不声称是同一字体。
- 原片包含舞池灯束、窗户亮点、面条与蒸汽、柴犬爱心，以及结尾彩纸和星芒。复刻中这些均为 SVG 图元。

## 实现取舍

四种画面、剪辑界面和操作角色都拆成独立组件，使用同一帧时钟。手机和面板的移动使用经过平滑处理的镜头关键点，剪切会实际缩短轨道中的素材块。手臂以起终点控制曲线路径，图标跟随末端，避免只用一张图片平移代替动作。

原音轨直接复用，因此音乐和原片音效得到保留。手绘抖动、贴纸字体、素材纹理及各次细小摆动作近似处理；几何重建相比原片更整齐。没有使用原片的连续帧或静帧替代动画主体。
